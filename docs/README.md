## ✍️ Contributing Translations

To add a new language translation:
1. Create a new directory under `docs/<language-code>/` (e.g., `docs/ja/` or `docs/zh/`).
2. Copy `docs/en/README.md` into `docs/<language-code>/README.md` and translate the contents.
3. Update this file (`docs/README.md`) and the language selector at the top of the root `README.md`.
