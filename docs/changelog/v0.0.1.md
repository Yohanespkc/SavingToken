# 🌐 Release Notes — SavingToken v0.0.1

**Release Date:** September 28, 2026  
**Codename:** *Global Gateway & Multilingual Docs*  
**Git Tag:** `v0.0.1`

---

## 🌟 Executive Summary

SavingToken v0.0.1 introduces a comprehensive multilingual documentation architecture to facilitate global deployment, international enterprise audits, and community contributions. This release provides complete technical documentation in English and Indonesian, an internationalized `docs/` tree, a dedicated changelog ledger system under `docs/changelog/`, and refined cross-repository navigation.

---

## 🔑 Key Features Delivered

### 1. Multilingual Documentation Tree (`docs/`)
* **English Architecture & Developer Documentation (`docs/en/README.md`)**:
  * Complete English translation covering every system tier, ASCII architecture diagrams, mathematical equations, configuration flags, and model specifications.
* **Indonesian Canonical Documentation (`docs/id/README.md`)**:
  * Standardized documentation preserving native terminology and telecom billing references.
* **Documentation Hub (`docs/README.md`)**:
  * Language matrix, quick topic links, and contribution guidelines for internationalization.

### 2. Dedicated Changelog Ledger (`docs/changelog/`)
* Established a structured directory for versioning records:
  * [`README.md`](README.md): Consolidated historical ledger following *Keep a Changelog* and *SemVer*.
  * [`v0.0.0.md`](v0.0.0.md): Genesis release specifications.
  * [`v0.0.1.md`](v0.0.1.md): Multilingual architecture release notes.
  * [`CHANGELOG_ID.md`](CHANGELOG_ID.md): Full Indonesian translation of changelog records.

### 3. Repository Navigation & Link Hardening
* Embedded language selection bars across the root `README.md` and documentation entries.
* Replaced local absolute file system links with robust relative repository paths.
* Updated root and internal directory trees to include `docs/` and `docs/changelog/`.
